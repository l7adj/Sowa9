# إدارة مهام السواق — Sowa9

نظام محلي لإدارة وتوزيع مهام السواق بطريقة عادلة وقابلة للمراجعة.

## الفكرة
- ترتيب المهمات ثابت، بينما الأيام قابلة للتعديل.
- التسجيل يكون للتوزيع الفعلي، مع دعم المخطط والاستثناءات.
- اختيار الدور يعتمد على السجل التاريخي الكامل، وليس على نافذة أربعة أسابيع فقط.
- حساب الراحة يكون زمنيًا كفترة متصلة بين نهاية مهمة وبداية المهمة التالية.
- الاستلاف والتسليف والعطلة والعجز تُسجل ولا تمحو التاريخ.
- الغابة لها منطقها الخاص: Alpha وMO وأدوار الفترات.

## تشغيل
افتح `index.html` مباشرة في المتصفح. التطبيق يعمل محليًا ويستخدم LocalStorage.
